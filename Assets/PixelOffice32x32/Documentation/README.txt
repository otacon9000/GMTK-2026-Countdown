PIXEL OFFICE 32x32
Version 2.0.0

OVERVIEW
Pixel Office 32x32 is a modular top-down pixel art pack for building office interiors in Unity.

QUICK START
1. Open the demo scene:
   Assets/PixelOffice32x32/Scenes/PixelOffice_Demo.unity

2. Open the Tile Palette:
   Window > 2D > Tile Palette

3. Select:
   PixelOffice_Environment

4. Drag character prefabs from:
   Assets/PixelOffice32x32/Prefabs/Characters

5. Drag the door prefab from:
   Assets/PixelOffice32x32/Prefabs/Environment

DOOR PREFAB
The Door prefab uses an Animator Controller with the Boolean parameter:

IsOpen = false  -> Closed
IsOpen = true   -> Open

PACKAGE CONTENTS
- 32x32 pixel art sprites
- 5 standing character prefabs with Idle and Walk animations
- 3 seated character prefabs with Work animations
- 8 character prefabs in total
- 15 animation clips in total
- 9 Animator Controllers in total
- 1 animated door prefab
- 1 Tile Palette
- 1 complete demo scene
- Modular floors, walls, windows, doors, furniture, office equipment, and decorations

IMPORT SETTINGS
- Pixels Per Unit: 32
- Filter Mode: Point
- Compression: None
- Sprite workflow: SpriteRenderer / Animator / Grid / Tilemap

UNITY PACKAGES USED
- 2D Sprite
- 2D Tilemap Editor

No custom scripts, shaders, or third-party Asset Store dependencies are required.
